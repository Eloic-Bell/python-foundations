What I learnt:
- for c in s:, this line of code allows you to scan through each character, c, which is in s. this type of code is useful for checking, changing or counting letters
- while loops repeat whilst a condition is true. use case: when number of repetition isn't known in advance
- you can use 'break' to exit a loop
- for loops are useful for looping through a sequence e.g. lists, str, or range of numbers
- range() used to create a sequence of numbers to repeat something a specified number of times
- '_' is used when a loop variable isn't required
- keeping your code clear and readable is extremely important especially when multiple conditions must be met
