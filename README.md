**Week 2: Conditionals** 
- date: 28/07/26

What I learnt:
- using if, elif and else to make decisions
- comparing values using == (equals), != (doesn't equal), < (less than), > (greater than), <= (less than or equal to), >= (greater than or equal to)
- Combining conditions using and, or and not
- Using match to compare one value against several possible cases
- Controlling conditional statements using Boolean values, True or False
- Comparison operators produce a Boolean result

Examples I wrote:
- Compare.py, a program which compares two values given by user and compares which value is greater than the other or if they are equal.
- Grade.py, a program which gives you a grade depending on the score you got in your test, using if, elif and else
- House.py, a program which asks user for a name and matches them to a house in harry potter using match and cases
- Parity.py, a program which uses Boolean values to determine weather a number is odd or even based on its remainder when divided by two
- Calculator.py a program which uses if, elif and else statements to get user input and perform simple arithmetic operations on two numbers
