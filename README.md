  **Week 1: Functions and Variables**
- date: 27/07/26
What I learnt:
- print() function to display text
- Storing information in variables
- input() function to ask for user input
- string methods such as:
strip() -removes spaces from left to right 
lstrip() -strips left spaces 
rstrip() -strips space from right 
capitalise() -capitalises first letter of first word
title() -capitalizes first letter of each word 
split("") - splits user input into different specified variables
int() -turns a string into an integer
float() - turns variable into a number allowing decimals 
round() - rounds number to nearest integer
def() - defines/invents/creates  a function
pow(n, x)- allows you to do to the power of for a number
- return, returns operation from secondary function back to main function where it can be stored in a variable and then used or printed 

Examples I wrote:
- Name.py a program which asks the user for their name and prints it out without any white space and with the first letter of the first and last name capitalised.
- Simple_calculator.py , a program which ask user to input two numbers and can do addition, subtraction and division. It organises answer with f strings and round(). Also has two defined functions allowing user to square a number using pow(n, 2) and return.
- Side_effects.py uses global to change a variable in a defined function
- Return.py uses def and return to calculate the area of a rectangle 

Problems I encountered:
